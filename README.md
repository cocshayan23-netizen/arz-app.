# اپلیکیشن قیمت ارز (Kivy)

## اجرا روی کامپیوتر (برای تست، قبل از ساخت APK)

```bash
pip install -r requirements.txt
python main.py
```

پنجره‌ای باز می‌شه با سه تب: بین‌المللی، کریپتو، بازار آزاد ایران.
دو تب اول از API واقعی و رایگان داده می‌گیرن. تب سوم فعلاً داده نمونه
(mock) نشون می‌ده چون منبع رایگان و پایدار برای نرخ بازار آزاد ایران
وجود نداره — باید بعداً یک منبع واقعی (مثلاً یک API پولی یا اسکرپینگ
یک سایت معتبر) جایگزینش کنی.

## ساخت فایل APK برای اندروید

این مرحله فقط روی **لینوکس یا WSL** جواب می‌ده (نه ویندوز مستقیم، نه مک به‌سادگی).

```bash
pip install buildozer cython
buildozer android debug
```

- اولین بار که اجرا می‌کنی، Buildozer به‌صورت خودکار Android SDK/NDK رو
  دانلود می‌کنه (ممکنه طول بکشه، چند گیگابایت حجم داره).
- در پایان یک فایل `.apk` داخل پوشه `bin/` ساخته می‌شه.
- اون فایل رو به گوشی اندرویدت منتقل کن و نصبش کن (باید نصب از
  منابع ناشناس رو فعال کنی).

## قدم بعدی پیشنهادی

1. تست کن ببین تب بین‌المللی و کریپتو درست قیمت نشون می‌دن.
2. یک منبع واقعی برای نرخ بازار آزاد ایران پیدا کن و `fetch_iran_market_rates`
   رو در `main.py` بر همون اساس بازنویسی کن.
3. ظاهر (رنگ‌بندی، فونت فارسی، آیکون) رو بهتر کن.
4. بعد از رضایت از ظاهر و عملکرد، `buildozer android debug` رو بزن و APK بگیر.
